

## TITLE
 Develop an admin dashboard with
CSS Grid layout and dynamic theme switching.

## Features
- Sidebar menu
- Top navigation bar
- Dashboard cards
- Dark / Light mode

## Technologies Used
- HTML
- CSS Grid
- JavaScript

## How to Run
1. Download or clone the project.
2. Open index.html in any browser.
3. Click on Change Theme button to switch mode.

## Deployment
This project is deployed using Netlify.
